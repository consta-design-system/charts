## Обзор

Компонент `Column` отображает столбчатую диаграмму (column chart). Поддерживает простые столбцы, стековые диаграммы, группированные столбцы, вывод значений на столбиках и группировку по цвету. Основан на G2Plot.

## Импорт

```tsx
import { Column } from '@consta/charts/Column';
```

## Свойства

| Свойство                                | Тип                   | По умолчанию | Описание                                        |
| --------------------------------------- | --------------------- | ------------ | ----------------------------------------------- |
| [`data`](#данные)                       | `Data[]`              | —            | Массив данных для диаграммы                     |
| [`xField`](#данные)                     | `string`              | —            | Поле данных для оси X (позиция/подпись столбца) |
| [`yField`](#данные)                     | `string`              | —            | Поле данных для оси Y (высота столбца)          |
| [`seriesField?`](#группировка-по-цвету) | `string`              | —            | Поле для группировки/окраски столбцов           |
| [`isStack?`](#стековая-диаграмма)       | `boolean`             | —            | Включает стековую диаграмму                     |
| [`isGroup?`](#группы-столбцов)          | `boolean`             | —            | Включает группировку столбцов                   |
| [`label?`](#значение-на-столбике)       | `ColumnLabel`         | —            | Настройки вывода значений на столбиках          |
| `meta?`                                 | `Record<string, any>` | —            | Форматирование данных для тултипа               |
| `className?`                            | `string`              | —            | Дополнительный CSS-класс                        |

<MdxInformer status="warning">

Если включить `isStack` без `seriesField`, части столбцов будут накладываться друг на друга.

</MdxInformer>

## Содержимое

### Данные

Основные данные передаются в свойстве `data`. Каждый элемент массива должен содержать как минимум два поля: значение для оси X (указывается в `xField`) и значение для оси Y (указывается в `yField`).

<MdxTabs>

<ColumnExampleSimple />

```tsx
const dataSimple = [
  { parameter: 'Параметр 1', number: 1234 },
  { parameter: 'Параметр 2', number: 1083 },
  { parameter: 'Параметр 3', number: 672 },
  { parameter: 'Параметр 4', number: 301 },
  { parameter: 'Параметр 5', number: 167 },
];

export function ColumnExampleSimple() {
  return (
    <Column
      style={{ marginBottom: 'var(--space-m)', maxWidth: 500, maxHeight: 200 }}
      data={dataSimple}
      xField="parameter"
      yField="number"
    />
  );
}
```

</MdxTabs>

### Значение на столбике

Для вывода значений на столбиках используйте свойство `label`. Подробные настройки доступны в [документации G2Plot](https://g2plot.antv.vision/en/docs/api/plots/column#label).

<MdxTabs>

<ColumnExampleLabel />

```tsx
export function ColumnExampleLabel() {
  return (
    <Column
      style={{ marginBottom: 'var(--space-m)', maxWidth: 300, maxHeight: 200 }}
      data={dataSimple}
      xField="parameter"
      yField="number"
      label={{
        position: 'middle',
        layout: [
          { type: 'interval-adjust-position' },
          { type: 'interval-hide-overlap' },
          { type: 'adjust-color' },
        ],
      }}
    />
  );
}
```

</MdxTabs>

### Группировка по цвету

Свойство `seriesField` позволяет окрашивать столбцы в разные цвета по значению указанного поля.

<MdxTabs>

<ColumnExampleSeriesField />

```tsx
export function ColumnExampleSeriesField() {
  return (
    <Column
      style={{ marginBottom: 'var(--space-m)', maxWidth: 400, maxHeight: 200 }}
      data={dataSimple}
      legend={getLegend({ layout: 'horizontal', position: 'top-left' })}
      renderer="svg"
      xField="parameter"
      yField="number"
      seriesField="parameter"
    />
  );
}
```

</MdxTabs>

## Внешний вид

### Стековая диаграмма

Установите `isStack={true}` и укажите `seriesField`, чтобы собрать несколько значений в один столбик.

<MdxTabs>

<ColumnExample />

```tsx
type Item = {
  name: string;
  month: string;
  value: number;
};

const data: Item[] = [
  {
    name: 'London',
    month: 'Jan.',
    value: 18.9,
  },

  // ...
  {
    name: 'London',
    month: 'Feb.',
    value: 28.8,
  },
];

export function ColumnExample() {
  return;
  <Column
    data={data}
    xField="month"
    yField="value"
    seriesField="name"
    isStack
    label={{
      position: 'middle',
      layout: [
        { type: 'interval-adjust-position' },
        { type: 'interval-hide-overlap' },
        { type: 'adjust-color' },
      ],
    }}
  />;
}
```

</MdxTabs>

### Группы столбцов

Установите `isGroup={true}` и укажите `seriesField`, чтобы разместить связанные столбцы рядом друг с другом.

<MdxTabs>

<ColumnExampleGroup />

```tsx
type Item = {
  name: string;
  month: string;
  value: number;
};

const data: Item[] = [
  {
    name: 'London',
    month: 'Jan.',
    value: 18.9,
  },

  // ...
  {
    name: 'London',
    month: 'Feb.',
    value: 28.8,
  },
];

function ColumnExampleGroup() {
  return (
    <Column
      data={data}
      xField="month"
      yField="value"
      seriesField="name"
      isGroup
      label={{
        position: 'middle',
        layout: [
          { type: 'interval-adjust-position' },
          { type: 'interval-hide-overlap' },
          { type: 'adjust-color' },
        ],
      }}
    />
  );
}
```

</MdxTabs>

## Пример использования

```tsx
import { Column } from '@consta/charts/Column';

const data = [
  { month: 'Янв', sales: 120 },
  { month: 'Фев', sales: 180 },
  { month: 'Мар', sales: 150 },
];

<Column data={data} xField="month" yField="sales" />;
```
