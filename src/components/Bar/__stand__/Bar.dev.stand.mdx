## Обзор

Компонент `Bar` отображает столбчатую диаграмму (bar chart) на основе библиотеки G2Plot. Подходит для сравнения значений по категориям, визуализации распределения данных или показа прогресса. Поддерживает простые столбцы, группировку по цвету, стековую и групповую компоновку.

## Импорт

```tsx
import { Bar } from '@consta/charts/Bar';
```

## Свойства

<MdxInformer status="normal">

Компонент основан на [G2Plot Bar](https://g2plot.antv.vision/en/docs/api/plots/bar). Многие свойства и настройки (например, `label`, `meta`) наследуются напрямую из библиотеки.

</MdxInformer>

| Свойство                                | Тип                     | По умолчанию | Описание                                           |
| --------------------------------------- | ----------------------- | ------------ | -------------------------------------------------- |
| [`data`](#содержимое)                   | `Record<string, any>[]` | —            | Массив данных для диаграммы                        |
| [`xField`](#содержимое)                 | `string`                | —            | Поле данных для значений по оси X (длина столбцов) |
| [`yField`](#содержимое)                 | `string`                | —            | Поле данных для категорий по оси Y                 |
| [`seriesField?`](#группировка-по-цвету) | `string`                | —            | Поле для группировки по цвету или серии            |
| [`isStack?`](#стековая-диаграмма)       | `boolean`               | `false`      | Включает стековую компоновку                       |
| [`isGroup?`](#группы-столбцов)          | `boolean`               | `false`      | Включает групповую компоновку столбцов             |
| [`label?`](#значение-на-столбике)       | `object`                | —            | Настройки отображения значений на столбцах         |
| `meta?`                                 | `object`                | —            | Форматирование данных для тултипа и осей           |
| `className?`                            | `string`                | —            | Дополнительный CSS-класс                           |

## Содержимое

Данные передаются в свойство `data` как массив объектов. Каждому столбцу соответствуют минимум два поля:

- значение по оси X (`xField` — длина столбца),
- категория по оси Y (`yField` — подпись и позиция).

<MdxTabs>

<BarExampleSimple />

```tsx
const dataSimple = [
  { parameter: 'Параметр 1', number: 1234 },
  { parameter: 'Параметр 2', number: 1083 },
  { parameter: 'Параметр 3', number: 672 },
  { parameter: 'Параметр 4', number: 301 },
  { parameter: 'Параметр 5', number: 167 },
];

export function BarExampleSimple() {
  return (
    <Bar
      style={{ marginBottom: 'var(--space-m)', maxWidth: 300, maxHeight: 200 }}
      data={dataSimple}
      xField="number"
      yField="parameter"
    />
  );
}
```

</MdxTabs>

### Значение на столбике

Свойство `label` управляет выводом значений непосредственно на столбцах. Подробные настройки доступны в [документации G2Plot](https://g2plot.antv.vision/en/docs/api/plots/bar#label).

<MdxTabs>

<BarExampleLabel />

```tsx
export function BarExample() {
  return (
    <Bar
      style={{ marginBottom: 'var(--space-m)', maxWidth: 300, maxHeight: 200 }}
      data={dataSimple}
      xField="number"
      yField="parameter"
      label={{
        position: 'middle',
        layout: [
          { type: 'interval-adjust-position' },
          { type: 'interval-hide-overlap' },
          { type: 'adjust-color' },
        ],
      }}
    />
  );
}
```

</MdxTabs>

## Группировка

### Группировка по цвету

Свойство `seriesField` позволяет окрашивать столбцы в разные цвета по значению указанного поля.

<MdxTabs>

<BarExampleSeriesField />

```tsx
export function BarExampleSeriesField() {
  return (
    <Bar
      style={{ marginBottom: 'var(--space-m)', maxWidth: 400, maxHeight: 200 }}
      data={dataSimple}
      xField="number"
      yField="parameter"
      seriesField="parameter"
    />
  );
}
```

</MdxTabs>

### Стековая диаграмма

Установите `isStack={true}` для суммирования значений в один столбец. Поле `seriesField` определяет, какие данные складывать.

<MdxInformer status="warning">

Без `isStack` части столбцов накладываются друг на друга.

</MdxInformer>

<MdxTabs>

<BarExample />

```tsx
type Item = {
  name: string;
  month: string;
  value: number;
};

const data: Item[] = [
  {
    name: 'London',
    month: 'Jan.',
    value: 18.9,
  },
  // ...
  {
    name: 'London',
    month: 'Feb.',
    value: 28.8,
  },
];

export function BarExample() {
  return (
    <Bar
      style={{ marginBottom: 'var(--space-m)' }}
      data={data}
      xField="value"
      yField="month"
      seriesField="name"
      isStack
    />
  );
}
```

</MdxTabs>

### Группы столбцов

Установите `isGroup={true}` для размещения связанных столбцов рядом в группы. Поле `seriesField` определяет группировку.

<MdxTabs>

<BarExampleGroup />

```tsx
type Item = {
  name: string;
  month: string;
  value: number;
};

const data: Item[] = [
  {
    name: 'London',
    month: 'Jan.',
    value: 18.9,
  },
  // ...
  {
    name: 'London',
    month: 'Feb.',
    value: 28.8,
  },
];

export function BarExampleGroup() {
  return (
    <Bar
      style={{ marginBottom: 'var(--space-m)' }}
      data={data}
      xField="value"
      yField="month"
      seriesField="name"
      isGroup
      label={{
        position: 'middle',
        layout: [
          { type: 'interval-adjust-position' },
          { type: 'interval-hide-overlap' },
          { type: 'adjust-color' },
        ],
      }}
    />
  );
}
```

</MdxTabs>
