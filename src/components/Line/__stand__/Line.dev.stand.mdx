## Обзор

Компонент `Line` отображает линейный график на основе библиотеки G2Plot. Подходит для визуализации временных рядов, трендов и сравнения данных. Поддерживает одну или несколько линий, настройку цветов, форматирование тултипа и масштабирование с помощью слайдера.

## Импорт

```tsx
import { Line } from '@consta/charts/Line';
```

## Свойства

<MdxInformer status="normal">

Компонент построен на базе G2Plot. [Полное описание API](https://g2plot.antv.vision/en/docs/api/plots/line).

</MdxInformer>

| Свойство                          | Тип                                    | По умолчанию | Описание                                                                |
| --------------------------------- | -------------------------------------- | ------------ | ----------------------------------------------------------------------- |
| [`data`](#одна-линия)             | `Record<string, any>[]`                | —            | Массив данных для графика                                               |
| [`xField`](#одна-линия)           | `string`                               | —            | Ключ объекта данных для оси X                                           |
| [`yField`](#одна-линия)           | `string`                               | —            | Ключ объекта данных для оси Y                                           |
| [`seriesField`](#несколько-линий) | `string`                               | —            | Ключ объекта данных для группировки по сериям (несколько линий)         |
| [`lineStyle`](#цвет-линий)        | `object \| ((series?: any) => object)` | —            | Стиль линии (цвет, толщина и др.)                                       |
| [`meta`](#тултип)                 | `object`                               | —            | Форматирование данных в тултипе (алиасы полей, форматирование значений) |
| [`slider`](#масштабирование)      | `object`                               | —            | Настройки слайдера для масштабирования графика                          |
| `className`                       | `string`                               | —            | Дополнительный CSS-класс компонента                                     |

## Содержимое

### Одна линия

Для отображения одной линии передайте массив данных в `data`. Укажите ключи для осей X и Y через свойства `xField` и `yField`.

<MdxTabs>

<LineExampleOneLine />

```tsx
type Item = { Date: string; scales: number };

const data: Item[] = [
  {
    Date: '2010-01',
    scales: 1998,
  },
  // ...
  {
    Date: '2010-02',
    scales: 1850,
  },
];

function LineExampleOneLine() {
  return <Line data={data} xField="Date" yField="scales" />;
}
```

</MdxTabs>

### Несколько линий

Чтобы отобразить несколько линий, добавьте свойство `seriesField` — ключ, по которому данные группируются.

<MdxTabs>

<LineExampleMultiLine />

```tsx
type Item = { country: string; year: string; value: null | number };

const data: Item[] = [
  { country: 'United Kingdom', year: '1915', value: 2.2 },
  // ...
  { country: 'United States', year: '1915', value: 0.7 },
];

function LineExampleMultiLine() {
  return (
    <Line data={data} xField="year" yField="value" seriesField="country" />
  );
}
```

</MdxTabs>

### Цвет линий

Цвет линии задаётся через свойство `lineStyle`. Для одной линии — объект стилей, для нескольких — функция, принимающая данные серии.

<MdxTabs>

<LineExampleColorLine />

```tsx
function LineExampleColorLine() {
  return (
    <Line
      data={data}
      xField="Date"
      yField="scales"
      lineStyle={{ stroke: 'red' }}
    />
  );
}
```

</MdxTabs>

<MdxTabs>

<LineExampleColorMultiLine />

```tsx
const colorMap: { [key: string]: string } = {
  'Austria': '#ff7514',
  'Canada': '#ad4800',
  'France': '#ca3a27',
  'Germany': '#470d0b',
  'Japan': '#ffc0cb',
  'Netherlands': '#ffd88a',
  'New Zealand': '#b39929',
  'Spain': '#c5e384',
  'Sweden': '#8c4566',
  'Switzerland': '#924e7d',
  'United Kingdom': '#905d5d',
  'United States': '#a2a2d0',
};

export function LineExampleColorMultiLine() {
  return (
    <Line
      data={data}
      xField="year"
      yField="value"
      seriesField="country"
      lineStyle={({ country }) => {
        return {
          stroke: colorMap[country],
        };
      }}
    />
  );
}
```

</MdxTabs>

## Тултип

Настройте отображение данных в тултипе с помощью свойства `meta`. Можно задать алиасы полей и формат значений.

<MdxTabs>

<LineExampleMeta />

```tsx
type Item = { Date: string; scales: number }

const data: Item[] = [
  {
    Date: '2010-01',
    scales: 1998,
  },
  // ...
  {
    Date: '2010-02',
    scales: 1850,
  },
]

function LineExampleMeta() {
  return
  <Line
    data={data}
    xField="Date"
    yField="scales"
    meta={{
      Date: {alias: 'Дата'},
      scales : {alias: 'Число'},
      }}
    }
  />
}
```

</MdxTabs>

## Масштабирование

Если график не помещается по ширине, добавьте слайдер через свойство `slider`. Стилизацию слайдера можно выполнить с помощью хука [useSlider](##LIBS.LIB.STAND/lib:charts/stand:hooks-useslider-stable).

<MdxTabs>

<LineExampleSlider />

```tsx
export function LineExampleSlider() {
  return (
    <Line
      style={{ marginBottom: 'var(--space-m)' }}
      data={data}
      xField="year"
      yField="value"
      seriesField="country"
      slider={{
        start: 0.1,
        end: 0.5,
      }}
    />
  );
}
```

</MdxTabs>
