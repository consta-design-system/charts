## Обзор

Компонент `Radar` отображает радарную (паутинообразную) диаграмму для визуализации многомерных данных. Подходит для сравнения одного или нескольких объектов по набору характеристик.

## Импорт

```tsx
import { Radar } from '@consta/charts/Radar';
```

## Свойства

| Свойство                              | Тип                     | По умолчанию | Описание                                         |
| ------------------------------------- | ----------------------- | ------------ | ------------------------------------------------ |
| [`data`](#данные)                     | `Record<string, any>[]` | —            | Массив данных для построения диаграммы           |
| [`xField`](#один-объект)              | `string`                | —            | Поле с названием характеристик (направляющих)    |
| [`yField`](#один-объект)              | `string`                | —            | Поле со значениями по характеристикам            |
| [`seriesField?`](#несколько-объектов) | `string`                | —            | Поле для группировки данных по линиям (объектам) |
| [`area?`](#линии)                     | `object`                | —            | Настройки заливки области под линией             |
| [`point?`](#линии)                    | `object`                | —            | Настройки точек на линии                         |
| [`xAxis?`](#сетка)                    | `object`                | —            | Настройки направляющих (радиальных осей)         |
| [`yAxis?`](#сетка)                    | `object`                | —            | Настройки круговой сетки                         |

<MdxInformer status="normal">

Компонент основан на G2Plot Radar. Подробное описание всех возможных настроек доступно в [документации G2Plot](https://g2plot.antv.vision/en/docs/api/plots/radar).

</MdxInformer>

## Содержимое

### Данные

Данные передаются в свойстве `data` в виде массива объектов. Каждый объект описывает значение одной характеристики для одного или нескольких сравниваемых сущностей.

### Один объект

Для отображения одного объекта укажите поля `xField` (названия характеристик) и `yField` (значения).

## Внешний вид

### Линии

Заливку области под линией можно включить через свойство `area`. Точки на линиях настраиваются в `point`.

<MdxTabs>

<RadarExampleArea />

```tsx
export function RadarExampleArea() {
  const options: RadarProps = {
    data,
    xField: 'skill',
    yField: 'star',
    seriesField: 'person',
    area: {},
    point: {
      size: 2,
    },
  };

  return <Radar {...options} />;
}
```

</MdxTabs>

### Сетка

Внешний вид радиальных направляющих задаётся в `xAxis`, круговой сетки — в `yAxis`.

<MdxTabs>

<RadarExampleAxis />

```tsx
export function RadarExampleAxis() {
  const options: RadarProps = {
    data,
    xField: 'skill',
    yField: 'star',
    seriesField: 'person',
    xAxis: {
      line: null,
      tickLine: null,
      grid: {
        line: {
          style: {
            lineDash: null,
          },
        },
      },
    },
    yAxis: {
      line: null,
      tickLine: null,
      grid: {
        line: {
          type: 'line',
          style: {
            lineDash: null,
          },
        },
      },
    },
    area: {},
    point: {
      size: 2,
    },
  };

  return <Radar {...options} />;
}
```

</MdxTabs>
