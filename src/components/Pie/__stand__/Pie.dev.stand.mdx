## Обзор

Компонент `Pie` отображает круговую или кольцевую (пончик) диаграмму. Поддерживает отображение данных в виде секторов, настройку внутреннего радиуса для пончика и статистики в центре.

## Импорт

```tsx
import { Pie } from '@consta/charts/Pie';
```

## Свойства

| Свойство                            | Тип                                                    | По умолчанию | Описание                                                             |
| ----------------------------------- | ------------------------------------------------------ | ------------ | -------------------------------------------------------------------- |
| [`data`](#данные)                   | `Record<string, any>[]`                                | —            | Массив данных для диаграммы                                          |
| `angleField`                        | `string`                                               | —            | Ключ поля, определяющего величину сектора                            |
| `colorField`                        | `string`                                               | —            | Ключ поля, определяющего название и цвет сектора                     |
| [`innerRadius`](#пончик)            | `number` (0–1)                                         | —            | Радиус внутреннего отверстия для пончика                             |
| [`statistic`](#статистика-в-центре) | `PieStatistic` \| `false`                              | —            | Настройка статистики в центре (работает при `innerRadius` > 0)       |
| [`formatter`](#статистика-в-центре) | `(text: string, item: ListItem, index: number) => any` | —            | Функция форматирования текстовых полей (тултип, легенда, статистика) |
| `className`                         | `string`                                               | —            | Дополнительный CSS-класс                                             |

## Содержимое

### Данные

Данные передаются в свойстве `data` в виде массива объектов. Каждый объект описывает один сектор диаграммы.

<MdxTabs>

<PieSimpleExample />

```tsx
const data = [
  { type: 'Вариант 1', value: 27 },
  { type: 'Вариант 2', value: 25 },
  { type: 'Вариант 3', value: 18 },
  { type: 'Вариант 4', value: 15 },
  { type: 'Вариант 5', value: 10 },
  { type: 'Вариант 6', value: 5 },
];

<Pie
  style={{ width: 800, height: '100%' }}
  data={data}
  angleField="value"
  colorField="type"
/>;
```

</MdxTabs>

## Внешний вид

### Пончик

Чтобы превратить круг в пончик, задайте `innerRadius` — относительный радиус внутреннего отверстия (от 0 до 1).

<MdxTabs>

<PieExampleDonut />

```tsx
<Pie
  style={{ width: 800, height: '100%' }}
  data={data}
  angleField="value"
  colorField="type"
  innerRadius={0.64}
  statistic={{
    title: false,
    content: false,
  }}
/>
```

</MdxTabs>

<MdxInformer status="normal">

Если нужен пустой пончик без текста в центре, отключите статистику, передав `statistic={{ title: false, content: false }}`.

</MdxInformer>

### Статистика в центре

При `innerRadius` > 0 в центре отображается статистика (по умолчанию — сумма всех значений). Настройка осуществляется через свойство `statistic`.

- `title` — подпись (например, «Всего» или название сектора при наведении).
- `content` — значение (сумма или величина сектора).

Для кастомного форматирования используйте `statistic.title.formatter`, `statistic.content.formatter` или общее свойство `formatter`.

<MdxTabs>

<PieExample />

```tsx
type Item = { type: string; value: number };

const data: Item[] = [
  { type: 'Вариант 1', value: 27 },
  { type: 'Вариант 2', value: 25 },
  { type: 'Вариант 3', value: 18 },
  { type: 'Вариант 4', value: 15 },
  { type: 'Вариант 5', value: 10 },
  { type: 'Вариант 6', value: 5 },
];

function sum(array?: Item[]) {
  if (!array) {
    return '0';
  }
  let s: number = 0;
  for (const item of array) {
    s += item.value;
  }
  return s.toString();
}

<Pie
  style={{ width: 800, height: '100%' }}
  data={data}
  angleField="value"
  colorField="type"
  radius={1}
  statistic={{
    title: {
      formatter: (v) => v?.type || 'Всего',
      style: {
        color: vars.color.primary['--color-typo-primary'],
      },
    },
    content: {
      customHtml: (v, v2, v3, v4) => (
        <Text size="3xl" view="primary" lineHeight="m">
          {v3?.value || sum(v4)}
        </Text>
      ),
    },
  }}
  innerRadius={0.64}
  label={{
    type: 'inner',
    offset: '-50%',
    content: '{value}',
    style: {
      textAlign: 'center',
      fontSize: 14,
    },
  }}
  interactions={[
    { type: 'element-selected' },
    { type: 'element-active' },
    { type: 'pie-statistic-active' },
  ]}
/>;
```

</MdxTabs>
