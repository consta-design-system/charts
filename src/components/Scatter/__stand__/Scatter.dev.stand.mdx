## Обзор

Компонент `Scatter` отображает диаграмму рассеивания. Он позволяет визуализировать зависимость между двумя переменными, настраивать внешний вид точек как глобально, так и в зависимости от данных точки. При наведении на точку появляется тултип с информацией.

## Импорт

```tsx
import { Scatter } from '@consta/charts/Scatter';
```

## Свойства

| Свойство               | Тип                                                                      | По умолчанию | Описание                                             |
| ---------------------- | ------------------------------------------------------------------------ | ------------ | ---------------------------------------------------- |
| [`data`](#данные)      | `Record<string, unknown>[]`                                              | -            | Массив данных с информацией о точках                 |
| [`xField`](#данные)    | `string`                                                                 | -            | Ключ поля для значений по горизонтальной оси         |
| [`yField`](#данные)    | `string`                                                                 | -            | Ключ поля для значений по вертикальной оси           |
| [`color`](#цвет)       | `string \| string[]`                                                     | -            | Цвет точек или набор цветов                          |
| [`colorField`](#цвет)  | `string`                                                                 | -            | Ключ поля, от значения которого зависит цвет точки   |
| [`size`](#размер)      | `number \| [number, number]`                                             | -            | Размер точек или диапазон размеров                   |
| [`sizeField`](#размер) | `string`                                                                 | -            | Ключ поля, от значения которого зависит размер точки |
| [`shape`](#форма)      | `string \| string[]`                                                     | -            | Форма точек или набор форм                           |
| [`shapeField`](#форма) | `string`                                                                 | -            | Ключ поля, от значения которого зависит форма точки  |
| [`meta`](#тултип)      | `Record<string, { alias?: string; formatter?: (v: unknown) => string }>` | -            | Настройки отображения данных в тултипе               |
| `pointStyle?`          | `object`                                                                 | -            | Стили точек (например, прозрачность)                 |
| `style?`               | `React.CSSProperties`                                                    | -            | Стили контейнера компонента                          |
| `className?`           | `string`                                                                 | -            | Дополнительный CSS-класс                             |

## Данные

Передайте массив объектов в свойстве `data`. Каждый объект описывает одну точку.

Укажите ключи полей для осей в свойствах `xField` (горизонтальная ось) и `yField` (вертикальная ось).

<MdxTabs>

<ScatterExampleSimple />

```tsx
const data = [
  { x: 1, y: 2 },
  { x: 2, y: 3 },
  { x: 3, y: 4 },
  { x: 4, y: 5 },
  { x: 5, y: 6 },
  { x: 6, y: 7 },
  { x: 7, y: 8 },
  { x: 8, y: 9 },
];

<Scatter data={data} xField="x" yField="y" />;
```

</MdxTabs>

## Внешний вид точек

### Цвет

Установите единый цвет всех точек через свойство `color`.

<MdxTabs>

<ScatterExampleColor />

```tsx
const dataColor = [
  { temperature: 0, ufo: 0, place: 'Тмутаракань' },
  { temperature: 1, ufo: 0, place: 'Бобруйск' },
  { temperature: 3, ufo: 5, place: 'Тмутаракань'},
//..//..
]

<Scatter
  style={{ marginBottom: 'var(--space-m)', width: 300, height: 200 }}
  data={dataColor}
  xField="temperature"
  yField="ufo"
  color={'#ffd500'}
  size={5}
  shape= 'circle'
  pointStyle= {{
    fillOpacity: 1,
  }}
/>
```

</MdxTabs>

Чтобы цвет зависел от значения поля, используйте `colorField` и передайте массив цветов в `color`.

<MdxTabs>

<ScatterExampleColorField />


## Тултип

По умолчанию тултип показывает все поля точки. Настройте отображение через свойство `meta`: задайте псевдоним (`alias`) и форматирование (`formatter`).

<MdxTabs>

<ScatterExamplePseudo />

```tsx
<Scatter
  style={{ marginBottom: 'var(--space-l)', width: 300, height: 200 }}
  data={dataColor}
  xField="temperature"
  yField="ufo"
  colorField="place"
  color={['#ffd500', '#82cab2', '#193442', '#d18768', '#7e827a']}
  size={[4, 20]}
  sizeField="ufo"
  shape="circle"
  pointStyle={{
    fillOpacity: 1,
  }}
  meta={{
    temperature: {
      alias: 'Воздух',
      formatter: (v) => {
        return `${v}°`;
      },
    },
    ufo: {
      alias: 'Видели НЛО',
      formatter: (v) => {
        return `${v} раз`;
      },
    },
    place: { alias: 'Город' },
  }}
/>
```

</MdxTabs>

```tsx
import { useThemeVars } from '@consta/uikit/useThemeVars';

const data = [
  {
    'iso3': 'ARE',

    'change in male rate': 3.3000000000000043,
    'female_2000': 1.9,
    'male_2000': 34.3,
    'female_2015': 1.2,
    'male_2015': 37.6,
    'income': 'High income',
    'pop': 9269612,
    'EN': 'United Arab Emirates',
    'DE': 'Vereinigte Arabische Emirate',
    'FR': 'Émirats arabes unis',
    'IT': 'Emirati Arabi Uniti',
    'ES': 'Emiratos Árabes Unidos',
    'PT': 'Emirados Árabes Unidos',
    'RU': 'Объединенные Арабские Эмираты',
    'ZH': '阿拉伯联合酋长国',
    'JA': 'アラブ首長国連邦',
    'AR': 'الإمارات العربية المتحدة',
    'continent': 'Asia',
  },
  //..//..
];

export function ScatterExample() {
  const vars = useThemeVars();
  return (
    <Scatter
      data={data}
      xField="change in female rate"
      appendPadding={30}
      yField="change in male rate"
      sizeField="pop"
      size={[4, 30]}
      shape="circle"
      colorField="continent"
      legend={{
        layout: 'horizontal',
        position: 'top-left',
        marker: {
          symbol: 'square',
        },
      }}
      pointStyle={{
        fillOpacity: 0.6,
        stroke: null,
      }}
      xAxis={{
        grid: {
          line: {
            style: {
              stroke: vars.color.primary['--color-bg-system'],
            },
          },
        },
        line: {
          style: {
            stroke: vars.color.primary['--color-bg-system'],
          },
        },
      }}
    />
  );
}
```
