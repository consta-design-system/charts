## Обзор

Компонент `DualAxes` позволяет отображать два набора данных на одном графике с двумя осями Y. Поддерживает комбинации линий, столбцов, стилизацию и масштабирование с помощью слайдера.

<MdxInformer status="normal">

Здесь описаны только основные свойства компонента. [Посмотреть все свойства](https://g2plot.antv.vision/en/docs/api/plots/dualaxes).

</MdxInformer>

## Импорт

```tsx
import { DualAxes } from '@consta/charts/DualAxes';
```

## Свойства

| Свойство                                       | Тип                | По умолчанию | Описание                                                                                                                          |
| ---------------------------------------------- | ------------------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| [`data`](#содержимое)                          | `Data[]`           | -            | Двумерный массив данных: `[данныеДляЛевойОсиY, данныеДляПравойОсиY]`                                                              |
| [`xField`](#содержимое)                        | `string`           | -            | Поле для горизонтальной оси X                                                                                                     |
| [`yField`](#содержимое)                        | `[string, string]` | -            | Массив полей для вертикальных осей Y (левая и правая)                                                                             |
| [`geometryOptions`](#две-линии-со-стилизацией) | `GeometryOption[]` | -            | Опции геометрии и стилизации для каждого набора данных                                                                            |
| [`slider`](#масштабирование)                   | `object`           | -            | Объект конфигурации слайдера. Стилизация доступна через хук [useSlider](##LIBS.LIB.STAND/lib:charts/stand:hooks-useslider-stable) |
| `className?`                                   | `string`           | -            | Дополнительный CSS-класс компонента                                                                                               |

## Содержимое

Данные передаются в свойство `data` как двумерный массив: `[левыйНаборДанных, правыйНаборДанных]`.  
Каждый набор — массив объектов с общим полем для оси X (`xField`) и отдельными полями для осей Y (`yField`).

### Две линии

<DualAxesExampleDualLine />

export const data = [
  { year: '1991', value: 3, count: 10 },
  { year: '1992', value: 4, count: 4 },

  { year: '1994', value: 5, count: 5 },

  { year: '1996', value: 6, count: 35 },
  { year: '1997', value: 7, count: 7 },
  { year: '1998', value: 9, count: 1 },
  { year: '1999', value: 13, count: 20 },

### Две линии со стилизацией

С помощью `geometryOptions` можно задать тип геометрии, цвет, толщину линий, точки и подписи.

<MdxTabs>

<DualAxesExampleDualLineWithStyle />

```tsx
export const data = [
  { year: '1991', value: 3, count: 10 },
  { year: '1992', value: 4, count: 4 },
  { year: '1993', value: 3.5, count: 5 },
  { year: '1994', value: 5, count: 5 },
  { year: '1995', value: 4.9, count: 4.9 },
  { year: '1996', value: 6, count: 35 },
  { year: '1997', value: 7, count: 7 },
  { year: '1998', value: 9, count: 1 },
  { year: '1999', value: 13, count: 20 },
];

export function DualAxesExampleDualLineWithStyle() {
  const vars = useThemeVars();
  return (
    <DualAxes
      data={[data, data]}
      xField="year"
      yField={['value', 'count']}
      geometryOptions={[
        {
          geometry: 'line',
          smooth: false,
          color: vars.color.primary['--color-bg-brand'],
          label: {
            formatter: (datum) => {
              return `${datum.value}`;
            },
          },
          lineStyle: {
            lineWidth: 3,
            lineDash: [5, 5],
          },
        },
        {
          geometry: 'line',
          smooth: true,
          color: vars.color.primary['--color-typo-success'],
          lineStyle: {
            lineWidth: 4,
            opacity: 0.5,
          },
          label: {
            formatter: (datum) => {
              return `${datum.count}`;
            },
          },
          point: {
            shape: 'circle',
            size: 4,
            style: {
              opacity: 0.5,
              stroke: vars.color.primary['--color-typo-success'],
              fill: vars.color.primary['--color-bg-default'],
            },
          },
        },
      ]}
    />
  );
}
```

</MdxTabs>

## Масштабирование

Если график не помещается по ширине, добавьте слайдер через свойство `slider`.  
Свойства `start` и `end` задают видимый диапазон (значения от 0 до 1).

<MdxTabs>

<DualAxesExampleSlider />

```tsx
export function DualAxesExampleSlider() {
  return (
    <DualAxes
      style={{ marginBottom: 'var(--space-m)' }}
      data={[data, data]}
      xField="year"
      slider={{
        start: 0,
        end: 0.5,
      }}
      yField={['value', 'count']}
    />
  );
}
```

</MdxTabs>
