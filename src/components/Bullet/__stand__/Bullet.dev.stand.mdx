## Обзор

Компонент `Bullet` отображает горизонтальные диаграммы-пули (bullet charts) для сравнения фактических значений с целевыми и фоновыми диапазонами. Подходит для визуализации прогресса, KPI или сравнения показателей.

<MdxInformer status="normal">

Полный список доступных свойств и возможностей смотрите в [документации G2Plot Bullet](https://g2plot.antv.vision/en/docs/api/plots/bullet).

</MdxInformer>

## Импорт

```tsx
import { Bullet } from '@consta/charts/Bullet';
```

## Свойства

| Свойство                    | Тип       | По умолчанию | Описание                                             |
| --------------------------- | --------- | ------------ | ---------------------------------------------------- |
| [`data`](#данные)           | `Data[]`  | —            | Массив с данными для линий                           |
| [`measureField`](#данные)   | `string`  | —            | Ключ в объекте данных для отрезков (measures)        |
| [`rangeField`](#данные)     | `string`  | —            | Ключ в объекте данных для фоновых диапазонов (range) |
| [`targetField`](#данные)    | `string`  | —            | Ключ в объекте данных для целевого значения (target) |
| [`xField`](#название-линии) | `string`  | —            | Ключ в объекте данных для названия линии             |
| [`yAxis`](#сетка)           | `boolean` | `true`       | Отображать ли вертикальную сетку и подписи осей      |
| `className`                 | `string`  | —            | Дополнительный CSS-класс                             |

## Содержимое

### Данные

Основные данные передаются в свойстве `data` — массив объектов. Каждый объект описывает одну горизонтальную линию.

В объекте можно указать:

- `range` — массив чисел для фоновых диапазонов (если одно значение — сплошной фон),
- `measures` — массив чисел для отрезков (фактические значения),
- `target` — число, целевое значение (отображается вертикальной полоской).

Пример структуры данных:

```tsx
const data = [
  {
    title: 'Наша первая цель',
    ranges: [50, 100],
    measures: [5, 20, 30, 25],
    target: 85,
  },
  {
    title: 'Наша вторая цель',
    ranges: [100],
    measures: [30],
    target: 70,
  },
];
```

Связывание ключей с полями данных:

```tsx
<Bullet
  data={data}
  measureField="measures"
  rangeField="ranges"
  targetField="target"
  xField="title"
/>
```

### Название линии

Название каждой линии (отображается слева) берётся из свойства `xField`. Укажите ключ в объекте данных, содержащий строку с названием.

## Внешний вид

### Сетка

По умолчанию отображается вертикальная сетка и подписи осей.

Чтобы скрыть сетку и оси, используйте `yAxis={false}`.

<BulletExampleNoAxys />

```tsx
<Bullet
  data={data}
  measureField="measures"
  rangeField="ranges"
  targetField="target"
  xField="title"
  yAxis={false}
/>
```

<BulletExample />

```tsx
const data = [
  { title: 'bullet1', ranges: [100], measures: [20, 30], target: 85 },
  { title: 'bullet2', ranges: [100], measures: [10, 50], target: 85 },
  { title: 'bullet3', ranges: [100], measures: [30, 10, 10, 10], target: 55 },
  { title: 'bullet4', ranges: [100], measures: [30], target: 60 },
  { title: 'bullet5', ranges: [100], measures: [45], target: 85 },
];

function BulletExample() {
  return (
    <Bullet
      data={data}
      measureField="measures"
      rangeField="ranges"
      targetField="target"
      xField="title"
      label={{
        measure: {
          position: 'middle',
          style: {
            fill: '#fff',
          },
        },
      }}
    />
  );
}
```
