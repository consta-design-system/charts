## Обзор

Компонент `Histogram` отображает гистограмму распределения данных. Поддерживает настройку количества и ширины столбцов, цвета, группировку значений (стековая гистограмма) и внешний вид сетки.

## Импорт

```tsx
import { Histogram } from '@consta/charts/Histogram';
```

## Свойства

## Данные

Гистограмма строится по одному числовому полю. Передайте массив объектов в свойство `data`, а имя поля — в `binField`.

<MdxTabs>

<HistogramExampleSuperBasic />

```tsx
export const data = [
  { value: 0 },
  { value: 0 },
  // ...
  { value: 17 },
  { value: 17 },
];

export function HistogramExampleBasic() {
  const options = {
    data,
    binField: 'value',
  };

  return <Histogram {...options} />;
}
```

</MdxTabs>

## Столбцы

### Количество столбцов

Управляйте количеством столбцов с помощью `binNumber` (фиксированное количество) или `binWidth` (фиксированная ширина). Одновременно использовать нельзя — выберите один вариант.

| `binNumber: 8`                  | `binWidth: 5`                  |
| ------------------------------- | ------------------------------ |
| <HistogramExampleBoxesNumber /> | <HistogramExampleBoxesWidth /> |

### Цвет столбцов

Цвет задаётся в свойстве `color`. Рекомендуется использовать токены темы. При группировке можно передать массив цветов.

<MdxTabs>

<HistogramExampleColor />

```tsx
export const data = [
  { value: 0 },
  { value: 0 },
  // ...
  { value: 17 },
  { value: 17 },
];

export function HistogramExampleColor() {
  const vars = useThemeVars();
  const options: HistogramProps = {
    data,
    binField: 'value',
    binWidth: 2,
    color: vars.color.primary['--color-bg-success'],
  };

  return <Histogram {...options} />;
}
```

</MdxTabs>

## Группы значений

Для построения стековой гистограммы добавьте поле группировки и укажите его в `stackField`. Цвета можно передать массивом в `color`.

<MdxTabs>

<HistogramExampleStacked />

```tsx
export const data = [
  { name: 'Blue', color: '#33ACF2', value: 4 },
  { name: 'Blue', color: '#33ACF2', value: 5 },
  // ...
  { name: 'Green', color: '#04BC7F', value: 0 },
  { name: 'Green', color: '#04BC7F', value: 1 },
  // ...
  { name: 'Orange', color: '#FFA217', value: 4 },
  { name: 'Orange', color: '#FFA217', value: 5 },
];

export function HistogramExampleBasic() {
  const options = {
    data,
    binField: 'value',
    stackField: 'name',
    binWidth: 4,
    color: ['#33ACF2', '#FFA217', '#04BC7F'],
    meta: {
      range: {
        tickInterval: 10,
      },
      count: {
        max: 50,
        nice: false,
      },
    },
    legend: {
      layout: 'horizontal',
      position: 'top-left',
      marker: {
        symbol: 'square',
      },
    },
  };

  return <Histogram {...options} />;
}
```

</MdxTabs>

## Сетка

Внешний вид осей и шкал настраивается через свойства `xAxis`, `yAxis` и `meta`.

<MdxTabs>

<HistogramExampleBasic />

```tsx
export const data = [
  { value: 0 },
  { value: 0 },
  // ...
  { value: 17 },
  { value: 17 },
];

export function HistogramExampleBasic() {
  const options = {
    data,
    binField: 'value',
    binWidth: 2,
    meta: {
      range: {
        tickInterval: 10,
      },
      count: {
        max: 40,
        nice: false,
      },
    },
    xAxis: {
      tickInterval: 5,
    },
  };

  return <Histogram {...options} />;
}
```

</MdxTabs>

## Пример использования

```tsx
import { Histogram } from '@consta/charts/Histogram';

const data = [
  { value: 5 },
  { value: 12 },
  { value: 8 },
  // ...
];

<Histogram data={data} binField="value" binWidth={2} />;
```
