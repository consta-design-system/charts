## Обзор

Компонент `Waterfall` отображает водопадную диаграмму, которая показывает последовательное накопление значений: положительные и отрицательные изменения, а также итоговую сумму. Подходит для визуализации финансовых потоков, изменений баланса или последовательных корректировок.

## Импорт

```tsx
import { Waterfall } from '@consta/charts/Waterfall';
```

## Свойства

| Свойство                          | Тип               | По умолчанию | Описание                                    |
| --------------------------------- | ----------------- | ------------ | ------------------------------------------- |
| [`data`](#данные)                 | `Data[]`          | -            | Массив данных для столбцов                  |
| [`xField`](#поля-данных)          | `string`          | -            | Ключ для значений по горизонтальной оси (X) |
| [`yField`](#поля-данных)          | `string`          | -            | Ключ для значений по вертикальной оси (Y)   |
| [`risingFill?`](#цвета-столбцов)  | `string`          | -            | Цвет столбцов увеличения                    |
| [`fallingFill?`](#цвета-столбцов) | `string`          | -            | Цвет столбцов уменьшения                    |
| [`total?`](#итоговый-столбец)     | `false \| object` | -            | Настройки итогового столбца                 |
| [`legend?`](#легенда)             | `false \| object` | -            | Настройки легенды                           |
| [`meta?`](#тултип)                | `object`          | -            | Форматирование данных в тултипе             |
| `yAxis?`                          | `false \| object` | -            | Настройки вертикальной оси и сетки          |
| `xAxis?`                          | `false \| object` | -            | Настройки горизонтальной оси и сетки        |
| `className?`                      | `string`          | -            | Дополнительный CSS-класс                    |

<MdxInformer status="normal">

Большинство свойств наследуются от G2Plot Waterfall. Подробное описание конфигурации доступно в [официальной документации](https://g2plot.antv.vision/en/docs/api/plots/waterfall).

</MdxInformer>

## Содержимое

### Данные

Передайте массив объектов в свойство `data`. Каждый объект описывает один столбец: значение и подпись.

<MdxTabs>

<WaterfallExampleSimple />

```tsx
const data = [
  { type: 'Тип 1', money: 120 },
  { type: 'Тип 2', money: 900 },
  { type: 'Тип 3', money: 200 },
  { type: 'Тип 4', money: 300 },
  { type: 'Тип 5', money: 1200 },
  { type: 'Тип 6', money: 1000 },
  { type: 'Тип 7', money: -2000 },
];

<Waterfall data={data} xField="type" yField="money" />;
```

</MdxTabs>

### Поля данных

Укажите ключи объекта данных:

- `xField` — подпись столбца (горизонтальная ось),
- `yField` — значение столбца (вертикальная ось).

## Внешний вид

### Цвета столбцов

Настройте цвета с помощью свойств `risingFill` (увеличение) и `fallingFill` (уменьшение).

<MdxTabs>

<WaterfallExampleColor />

```tsx
<Waterfall
  data={data}
  xField="type"
  yField="money"
  risingFill={vars.color.primary['--color-bg-success']}
  fallingFill={vars.color.primary['--color-bg-alert']}
  total={{
    style: {
      fill: vars.color.primary['--color-bg-system'],
    },
  }}
/>
```

</MdxTabs>

### Итоговый столбец

Свойство `total` добавляет и стилизует финальный столбец с общей суммой.

<MdxTabs>

<WaterfallExampleMeta />

```tsx
<Waterfall
  data={data}
  xField="type"
  yField="money"
  total={{
    style: {
      fill: vars.color.primary['--color-bg-system'],
    },
    label: 'Всего',
  }}
/>
```

</MdxTabs>

## Легенда

Настройте положение и вид легенды через свойство `legend`.

<MdxTabs>

<WaterfallExampleLegend />

```tsx
<Waterfall
  data={data}
  xField="type"
  yField="money"
  legend={{
    layout: 'horizontal',
    position: 'top-left',
    marker: {
      symbol: 'square',
    },
  }}
/>
```

</MdxTabs>

## Тултип

Свойство `meta` позволяет переименовать поля и задать формат отображения в тултипе.

<MdxTabs>

<WaterfallExampleMeta />

```tsx
<Waterfall
  data={data}
  xField="type"
  yField="money"
  meta={{
    money: {
      alias: 'На счете',
      formatter: (v) => `${v} ₽`,
    },
  }}
/>
```

</MdxTabs>

## Оси и сетка

Настройте оси и линии сетки через свойства `xAxis` и `yAxis`.

<MdxTabs>

<WaterfallExample />

```tsx
<Waterfall
  data={data}
  xField="type"
  yField="money"
  yAxis={{
    grid: {
      line: {
        style: {
          lineDash: null,
          stroke: vars.color.primary['--color-bg-system'],
        },
      },
    },
  }}
/>
```

</MdxTabs>

## Пример использования

```tsx
import { Waterfall } from '@consta/charts/Waterfall';

const data = [
  { type: 'Начальный баланс', money: 1000 },
  { type: 'Доход', money: 1500 },
  { type: 'Расход 1', money: -600 },
  { type: 'Расход 2', money: -400 },
];

<Waterfall
  data={data}
  xField="type"
  yField="money"
  risingFill="#00a680"
  fallingFill="#ff4d4f"
  total={{ label: 'Итог' }}
/>;
```
