## Обзор

Компонент `BidirectionalBar` отображает двустороннюю столбчатую диаграмму для визуального сравнения двух наборов значений по категориям. Подходит для демонстрации положительных и отрицательных отклонений, сравнения двух метрик или симметричного представления данных.

<MdxInformer status="normal">

Полный список свойств и возможностей доступен в [официальной документации](https://charts.ant.design/en/api/plots/bidirectional-bar).

</MdxInformer>

## Импорт

```tsx
import { BidirectionalBar } from '@consta/charts/BidirectionalBar';
```

## Свойства

| Свойство                    | Тип                          | По умолчанию | Описание                                |
| --------------------------- | ---------------------------- | ------------ | --------------------------------------- |
| [`data`](#данные)           | `Item[]`                     | —            | Массив объектов с данными для сравнения |
| [`xField`](#поля-сравнения) | `string`                     | —            | Поле для группировки (категория)        |
| [`yField`](#поля-сравнения) | `[string, string]`           | —            | Пара полей для сравниваемых значений    |
| [`layout?`](#ориентация)    | `'vertical' \| 'horizontal'` | —            | Ориентация графика                      |
| `className?`                | `string`                     | —            | Дополнительный CSS-класс                |

## Содержимое

### Данные

Основные данные передаются в свойстве `data` как массив объектов. Каждый объект должен содержать поле для группировки (обычно строковое) и два числовых поля для сравнения.

```tsx
type Item = {
  name: string;
  value1: number;
  value2: number;
};

const data: Item[] = [
  {
    name: 'Петя',
    value1: 13.4,
    value2: 12.3,
  },
  // ...
  {
    name: 'Саша',
    value1: 165.2,
    value2: 72.9,
  },
];
```

### Поля сравнения

- `xField` — имя поля, по которому происходит группировка (отображается по оси X в вертикальной ориентации или по оси Y в горизонтальной).
- `yField` — массив из двух строк: имена полей с числовыми значениями для сравнения.

<BidirectionalBarExample />

```tsx
export const BidirectionalBarExample = () => {
  return (
    <BidirectionalBar
      data={data}
      xField="name"

    />
  );
};
```

## Внешний вид

### Ориентация

Свойство `layout` управляет ориентацией графика:

- `'vertical'` — вертикальные столбцы (по умолчанию).
- `'horizontal'` — горизонтальные столбцы.

<MdxTabs>

<BidirectionalBarLayoutExample />

```tsx
<BidirectionalBar data={data} xField="name" yField={['value1', 'value2']} layout="vertical" />
<BidirectionalBar data={data} xField="name" yField={['value1', 'value2']} layout="horizontal" />
```
