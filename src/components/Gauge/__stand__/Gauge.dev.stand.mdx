## Обзор

Компонент `Gauge` отображает круговую шкалу с индикатором (стрелкой), дугой прогресса и возможностью добавить центральную статистику. Подходит для визуализации процентов выполнения, загрузки или других метрик в диапазоне 0–1.

<MdxInformer status="normal">

Компонент построен на базе G2Plot. [Полное описание API](https://g2plot.antv.vision/en/docs/api/plots/gauge).

</MdxInformer>

## Импорт

```tsx
import { Gauge } from '@consta/charts/Gauge';
```

## Свойства

| Свойство                    | Тип      | По умолчанию | Описание                                      |
| --------------------------- | -------- | ------------ | --------------------------------------------- |
| [`percent`](#положение)     | `number` | —            | Значение индикатора, от 0 до 1 (обязательное) |
| [`indicator`](#внешний-вид) | `object` | —            | Настройка внешнего вида стрелки-индикатора    |
| [`range`](#цвет)            | `object` | —            | Настройка дуги (шкалы прогресса)              |
| [`axis`](#деления)          | `object` | —            | Настройка делений и подписей шкалы            |
| [`statistic`](#статистика)  | `object` | —            | Настройка центральной статистики              |

## Индикатор

### Положение

За положение стрелки отвечает обязательное свойство `percent`. Принимает значение от 0 до 1, где 1 — полный круг.

<MdxTabs>

<GaugeExampleSimple />

```tsx
export function GaugeExample() {
  const options = {
    percent: 0.75,
  };

  return <Gauge {...options} />;
}
```

</MdxTabs>

### Внешний вид

Внешний вид стрелки настраивается через свойство `indicator`. Внутри можно отдельно стилизовать:

- `pointer` — саму стрелку,
- `pin` — центральный диск, к которому крепится стрелка.

<MdxTabs>

<GaugeExampleIndicator />

```tsx
export function GaugeExample() {
  const vars = useThemeVars();

  const options = {
    percent: 0.75,
    indicator: {
      pin: {
        style: {
          r: 16,
          stroke: vars.color.primary['--color-bg-border'],
          lineWidth: 6,
        },
      },
      pointer: {
        style: {
          stroke: vars.color.primary['--color-bg-alert'],
          lineWidth: 6,
        },
      },
    },
  };

  return <Gauge {...options} />;
}
```

</MdxTabs>

## Шкала

### Цвет

Цвет дуги прогресса задаётся в свойстве `range.color`.

<MdxTabs>

<GaugeExampleColor />

```tsx
export function GaugeExample() {
  const vars = useThemeVars();

  const options = {
    percent: 0.75,
    range: {
      color: vars.color.primary['--color-bg-success'],
    },
  };

  return <Gauge {...options} />;
}
```

</MdxTabs>

### Деления

Подписи делений настраиваются через `axis.label`. Деления второго уровня — через `axis.subTickLine`.

<MdxTabs>

<GaugeExampleScale />

```tsx
export function GaugeExample() {
  const vars = useThemeVars();

  const options = {
    percent: 0.75,
    range: {
      color: vars.color.primary['--color-bg-success'],
    },
    axis: {
      label: {
        formatter(v) {
          return Number(v) * 100;
        },
      },
      subTickLine: {
        count: 3,
      },
    },
  };

  return <Gauge {...options} />;
}
```

</MdxTabs>

## Статистика

В центре диаграммы можно разместить произвольный текст или значение через свойство `statistic`. Часто используется для отображения процента в читаемом виде.

<MdxTabs>

<GaugeExampleStatistic />

```tsx
export function GaugeExample() {
  const customFormatter = (
    data: Record<string, number> | undefined,
  ): string => {
    return data && typeof data.percent === 'number'
      ? `${(Number(data.percent) * 100).toFixed(0)}%`
      : '';
  };

  const vars = useThemeVars();

  const options = {
    percent: 0.75,
    range: {
      color: vars.color.primary['--color-bg-success'],
    },
    axis: {
      label: {
        formatter: (v: number) => Number(v) * 100,
      },
      subTickLine: {
        count: 3,
      },
    },
    statistic: {
      content: {
        formatter: customFormatter,
        style: {
          color: vars.color.primary['--color-bg-tone'],
        },
      },
    },
  };

  return <Gauge {...options} />;
}
```

</MdxTabs>

## Пример использования

<MdxTabs>

```tsx
export function GaugeExample() {
  const vars = useThemeVars();

  const options = {
    percent: 0.75,
    radius: 0.75,
    range: {
      color: [
        vars.color.primary['--color-bg-success'],
        vars.color.primary['--color-bg-ghost'],
      ],
    },
    gaugeStyle: {
      lineCap: 'round',
    },
    statistic: {
      content: {
        formatter: customFormatter,
        style: {
          color: vars.color.primary['--color-typo-primary'],
          fontSize: '24px',
          fontWeight: 'bold',
        },
      },
    },
    axis: {
      subTickLine: {
        count: 3,
        length: -8,
        style: {
          stroke: vars.color.primary['--color-control-bg-border-default'],
        },
      },
      tickLine: {
        length: -12,
        style: {
          stroke: vars.color.primary['--color-control-bg-border-default'],
        },
      },
      label: {
        style: {
          fontSize: 12,
        },
      },
    },
    indicator: {
      pin: {
        style: {
          r: 9,
          stroke: vars.color.primary['--color-control-bg-border-default'],
          lineWidth: 4,
          fill: vars.color.primary['--color-bg-default'],
        },
      },
      pointer: {
        style: {
          stroke: vars.color.primary['--color-control-bg-border-default'],
          lineWidth: 4,
        },
      },
    },
  };

  return <Gauge {...options} />;
}
```
