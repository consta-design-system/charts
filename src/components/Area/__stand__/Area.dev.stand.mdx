## Обзор

Компонент `Area` отображает площадный график (area chart). Подходит для визуализации изменений значения во времени или сравнения нескольких серий данных. Основан на G2Plot.

## Импорт

```tsx
import { Area } from '@consta/charts/Area';
```

## Свойства

<MdxInformer status="normal">

Свойства компонента основаны на [G2Plot Area](https://g2plot.antv.vision/en/docs/api/plots/area). Ниже перечислены основные, наиболее часто используемые свойства.

</MdxInformer>

| Свойство                          | Тип                                                                  | По умолчанию | Описание                                                                               |
| --------------------------------- | -------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| [`data`](#одна-линия)             | `Record<string, any>[]`                                              | —            | Массив данных для графика                                                              |
| [`xField`](#одна-линия)           | `string`                                                             | —            | Ключ поля для оси X                                                                    |
| [`yField`](#одна-линия)           | `string`                                                             | —            | Ключ поля для оси Y                                                                    |
| [`seriesField`](#несколько-линий) | `string`                                                             | —            | Ключ поля для группировки по сериям (несколько линий)                                  |
| [`color`](#цвет-линий)            | `string \| string[] \| ((datum: any) => string)`                     | —            | Цвет или массив цветов для линий                                                       |
| [`areaStyle`](#цвет-линий)        | `object \| ((datum: any) => object)`                                 | —            | Стили заливки области (например, `{ fill: string, stroke: string }`)                   |
| [`line`](#цвет-линий)             | `object`                                                             | —            | Стили линии (например, `{ style: { stroke: string } }`)                                |
| [`meta`](#формат-данных)          | `Record<string, { alias?: string; formatter?: (v: any) => string }>` | —            | Метаданные для форматирования значений в тултипе                                       |
| [`slider`](#масштабирование)      | `object`                                                             | —            | Конфигурация слайдера для масштабирования (например, `{ start: number; end: number }`) |
| `className`                       | `string`                                                             | —            | Дополнительный CSS-класс                                                               |

## Содержимое

### Одна линия

Для отображения одной линии достаточно указать данные и поля для осей X и Y.

<MdxTabs>

<AreaExampleOneLine />

```tsx
type Item = { Date: string; scales: number };

const data: Item[] = [
  {
    Date: '2010-01',
    scales: 1998,
  },
  // ...
  {
    Date: '2010-02',
    scales: 1850,
  },
];

function AreaExampleOneLine() {
  return <Area data={data} xField="Date" yField="scales" />;
}
```

</MdxTabs>

### Несколько линий

Для нескольких линий используйте `seriesField` — поле, по которому данные группируются.

<MdxTabs>

<AreaExampleMultiLine />

```tsx
type Item = { country: string; year: string; value: null | number };

const data: Item[] = [
  { country: 'Россия', year: '1915', value: 2.2 },
  // ...
  { country: 'Турция', year: '1915', value: 0.7 },
];

function AreaExampleMultiLine() {
  return (
    <Area data={data} xField="year" yField="value" seriesField="country" />
  );
}
```

</MdxTabs>

### Цвет линий

Цвета линий и заливки можно задать через `areaStyle`, `line` или `color`.

<MdxTabs>

<AreaExampleColorLine />

```tsx
function AreaExampleColorLine() {
  return (
    <Area
      style={{ marginBottom: 'var(--space-m)' }}
      data={oneAreaData}
      xField="Date"
      yField="scales"
      areaStyle={{ stroke: 'red', fill: 'red' }}
      line={{ style: { stroke: 'red' } }}
    />
  );
}
```

</MdxTabs>

## Тултип

### Формат данных

Свойство `meta` позволяет задать псевдонимы (`alias`) и форматирование значений в тултипе.

<MdxTabs>

<AreaExampleMeta />

```tsx
type Item = { Date: string; scales: number };

const data: Item[] = [
  {
    Date: '2010-01',
    scales: 1998,
  },
  // ...
  {
    Date: '2010-02',
    scales: 1850,
  },
];

function AreaExampleMeta() {
  return (
    <Area
      data={data}
      xField="Date"
      yField="scales"
      meta={{
        Date: { alias: 'Дата' },
        scales: { alias: 'Число' },
      }}
    />
  );
}
```

</MdxTabs>

## Масштабирование

Если график не помещается по ширине, добавьте слайдер с помощью свойства `slider`.

<MdxTabs>

<AreaExampleSlider />

```tsx
export function AreaExampleSlider() {
  return (
    <Area
      style={{ marginBottom: 'var(--space-m)' }}
      data={data}
      xField="year"
      yField="value"
      seriesField="country"
      slider={{
        start: 0,
        end: 0.5,
      }}
    />
  );
}
```

</MdxTabs>
